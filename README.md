# Лабораторная работа №3

**Дисциплина:** Распределительные системы обработки информации  
**Тема:** Вычисления на основе взаимодействия сервисов  
**Выполнил:** Гусев П.И., гр. 6413М

## Описание

Система на основе XML-RPC для обработки запросов через прокси-сервер с логированием статистики.

## Состав

- `xmlrpc_server.ipynb` - основной сервер (порт 8008)
- `xmlrpc_proxy_server.ipynb` - прокси-сервер с Rate Limiting (порт 8010)
- `xmlrpc_stats2_server.ipynb` - сервер статистики SQLite (порт 8009)
- `xmlrpc_client.ipynb` - клиент для тестирования

## Функционал

- Проверка чёрного списка
- Обработка изображений (инверсия, бинаризация, разворот)
- Rate Limiting (5 запросов в 5 секунд)
- Логирование событий в SQLite
- Фильтрация статистики по типу, времени, длительности

## Запуск

1. Запустить `xmlrpc_server.ipynb`
2. Запустить `xmlrpc_stats2_server.ipynb`
3. Запустить `xmlrpc_proxy_server.ipynb`
4. Запустить `xmlrpc_client.ipynb`
